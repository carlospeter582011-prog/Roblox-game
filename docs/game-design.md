# Catch a Cloud — Game Design

Canonical full design and agent handoff: https://app.notion.com/p/413edc0cac2381a4b42bd36df3e25183

Core loop: explore → locate a living cloud → chase and skill-catch → collect → bond/evolve/fuse → use in island and exploration → unlock story and worlds.

Launch vision: 10 worlds, 150+ clouds, 15+ tools, 100+ quests, 10 bosses, multiplayer, islands, guilds, trading, racing and seasons. These are targets, not implemented claims.

First vertical slice: starter island, Breeze Cloud, responsive touch interaction, server-authoritative catch, inventory persistence and onboarding in under two minutes.
